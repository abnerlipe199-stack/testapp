# Calculadora de Média Escolar

Um script em **Python** desenvolvido para automatizar o cálculo da média de notas de um aluno e verificar o seu status de aprovação de forma rápida pelo terminal.
---

## Tecnologias Utilizadas

- **Python 3**: Linguagem de programação utilizada para implementar a lógica de cálculo.
- **VS Code**: Ambiente de desenvolvimento integrado (IDE) para edição do código.
- **Git e GitHub**: Controlo de versões e alojamento do repositório.
---

## Como Instalar e Executar

1. Certifica-te de que tens o **Python 3** instalado no computador.
2. Abre a pasta do projeto no VS Code.
3. Abre o terminal do VS Code e executa o seguinte comando:

```bash
python app.py
---

## Exemplo de Uso

Ao executar o programa no terminal, o fluxo decorre da seguinte forma:

```text
=== Sistema de Notas do Aluno ===
Digite a primeira nota: 8.5
Digite a segunda nota: 7.0
A média final é: 7.75
Status: APROVADO!
---
